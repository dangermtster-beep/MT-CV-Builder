# MT CV Builder

Bu repo yalnızca **MT CV Builder** kurulum dosyalarını ve güncelleme bilgisini
barındırır. Program kurulduktan sonra yeni sürümleri kendisi denetler.

Kurulum için [Releases](../../releases/latest) sayfasındaki
`MT_CV_Builder_Setup_<sürüm>.exe` dosyasını indirin.

This repository only hosts **MT CV Builder** installers and update information.
